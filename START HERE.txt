SHORTSFORGE - HOW TO INSTALL (Windows 10 or 11)
================================================

1. Double-click "Install ShortsForge".
   - If Windows says "Windows protected your PC", click More info > Run anyway.
     This only appears because the file was downloaded from the internet.
   - Click Yes to install. The first start sets everything up (a few minutes),
     then ShortsForge opens in your web browser.

2. Keep the black window open while you work. Close it to stop ShortsForge.

3. Next time, open ShortsForge from your Desktop or the Start menu.

You can delete the downloaded ZIP and this folder after installing.


IF WINDOWS BLOCKS IT
--------------------
Click Start, type PowerShell, open it, paste this line and press Enter:

  irm https://raw.githubusercontent.com/asadpuremarketing-wq/Shortsforge/main/tools/install.ps1 | iex

It installs the same way without running any downloaded file.


UPDATES
-------
Nothing to do. Every time you start ShortsForge it checks for a new version
and installs it automatically. Your projects and settings are always kept.


UNINSTALL
---------
Settings > Apps > Installed apps > ShortsForge > Uninstall.
It asks whether to keep your projects.


GOOD TO KNOW
------------
- Your projects stay on your own computer.
- No API keys are needed to make ranking videos. Optional AI features
  can be turned on in Settings with your own keys.
- An NVIDIA graphics card makes rendering much faster, but it isn't required.
- Opens at: http://localhost:5173
